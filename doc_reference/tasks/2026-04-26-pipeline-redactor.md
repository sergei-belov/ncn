# Step 05 — Pipeline Redactor

## Goal
Сделать экран редактирования пайплайна на базе Vue Flow

## Business requirements

Экран предтавляет из себя настройки графа шагов (Steps) от начального состояния:

Начальное состояние - это тоже Шаг. Первый шаг который добавляется по умолчанию начальный

## Шаги (Steps)

Шаг представляет из себя простой набор действий с опциональными проверками.
Например:
```
step_name: "Нажать на кнопку добавления"
assertions:
  - "Появлется dialog c формой"
   - "Имя предзаполнено значением {{Value}}"
 ```
У шага так же могут быть другие сущности (html код страницы, переменные, локатор, в будущем скрины и тд.)

Некоторые требования:
- у каждого шага кроме начального есть входной и выходной узел
- У начального шага есть только выходной узел
- В каждый шаг может приходить только одна связь
- Любой шаг можно сделать начальным, если у него нет входных связей (при этом пропадает входной узел)
- Из каждого шага может выходить больше чем одина связь (разные сценарии в одном пайплайне)
- Начальных шагов может быть несколько (разные сценарии в одном пайплайне)


## Редактор пайплайна

При нажатии на любой Шаг, снизу у него появляется набор действий (поповер с кнопками в виде иконок):
- Открыть настройки (сайдбар справа AppSidebar, так же доступен по двойному клику)
- Зафиксировать (нельзя двигать)
- Дублировать
- Запустить
- Удалить
- Создать по действиям (из шага создаются все возможные действия относительно текущего положения страницы - нажимаются кнопки, активизируются инпуты и тд)

У каждого шага в верхнем углу висит круглый бейдж статуса (готов или не готов)

У каждого шага внизу отображается список assertions

При наведении на правый выходной узел появляется кнопка "+" (cоздать новый шаг)

У редактора есть выбор перед пкайплайнов и пост пайплайнов (что должно выполнится до пайплайна, например добавление в корзину товара)

Это можно сделать например через скрываемый сайдбар слева

Шаги можно выделять с кнопкой Shift.
- Тогда появляется возможность их множественного пермещения (на отдельный api эндпоинт)
- В нижней части экрана поялвяется набор действий (с кнопками в виде иконок аналогичный у шага, но внизу Vue flow). Из действий только удалить.

## Связи
Связи можно создавать нажав на узел и ведя к другому узлу (стандартный флоу)

Связи визуально сплошная линия. При hover на связи поялвется корзинка для удаления (с модалкой подтверждления)


## Логика
- Полчение списка шагов, пре и пост пайплайнов работает без пагинации, отправляя все шаги пайплайна и его данные (включая assertions)
- Изначально шаг пустой (html и селекторы), только название и описание
- Для заполнения шага нужно нажать на Запустить
- Запустить запускает проверку шага (через запуск playwrite), заполняет через code. Если есть селектор и assertions то по ним так же делается проверка, менятеся статус бейджа.
- Для самого шага, селектора и assertion должна быть доступна кнопка добавления переменных (Varialbes) в текстовые поля


## ЗАМЕТКИ
- Пока текущая реалзиаци без LLM агента. В будущем в наборе действий будут агенсткие действия - чат, автоматический выбор дейстий и тд.
