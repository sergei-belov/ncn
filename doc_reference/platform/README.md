## Описание платформы QAi

**QAi** — это интеллектуальная платформа для автоматизации тестирования веб-приложений с использованием возможностей LLM-моделей.

Платформа позволяет QA-инженерам и разработчикам быстро создавать и запускать автотесты без необходимости ручного написания кода. В центре платформы — концепция **графа действий**, которая описывает пользовательские сценарии на веб-сайте в виде логических шагов. На основе этих графов **LLM-модель** автоматически генерирует абстрактный Playwright-код, создает тесткейсы, выполняет тестирование и предоставляет результаты.

Основной фокус платформы — **снижение затрат на ручное тестирование**, **ускорение разработки автотестов**, и **повышение качества продукта через LLM-поддерживаемую автоматизацию**.

### Ключевые возможности:

* Простое создание проектов и сценариев
* Интеллектуальная генерация тестов с помощью LLM
* AI-assisted генерация draft тест-кейсов через preview-first workflow
* Интеграция с Playwright для запуска автотестов и получения HTML-контекста шагов
* Поддержка переменных и секретов для гибкости конфигурации
* Черновики пайплайнов и опубликованные версии тест-кейсов для управляемой истории изменений
* Граф проекта для описания страниц, состояний DOM, URL-нормализации и достижимости в тестируемом приложении
* Визуальный контроль шагов, preview-результатов и результатов тестов
* Масштабируемость и интеграция в CI/CD пайплайны

Платформа особенно полезна для команд, которые:

* Хотят быстро покрыть UI автотестами
* Не имеют ресурсов на сложную автоматизацию
* Ищут гибкое решение на базе ИИ, адаптирующееся под продукт
