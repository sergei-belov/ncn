## Feature Contract Requirements

Each `features/<feature-slug>.md` defines status, problem, actors, scope/non-goals, requirements/invariants, permissions, failures/recovery, acceptance, assumptions/open questions, and links to scenarios, UI/UX, APIs/events, models/tables, and decisions.

One service owns each feature. Other services link to this owner and specify only their consumer behavior.
